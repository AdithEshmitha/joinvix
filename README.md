# JOINVIX

A modern WhatsApp Channel directory platform for discovering and promoting channels.

## About

JOINVIX is a platform that helps users discover WhatsApp Channels
by category and search, while allowing channel owners to submit
their channels for free listing.

## Features

- Discover WhatsApp Channels
- Search and category filtering
- Free channel submission
- Channel approval system
- Admin dashboard
- Admin authentication
- Channel management

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
